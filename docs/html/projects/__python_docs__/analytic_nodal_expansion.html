analytic_nodal_expansion module¶

analytic_nodal_expansion.py

Analytic Function Expansion Nodal (AFEN) for 2-dim Boundary Value Problem is used to reconstruct the 2-dim flux within the assembly.

  1. The surface and corner fluxes are assumed to be known.

  2. Heterogeneous fluxes are employed as boundary values.

  3. The node is assumed to have dx=dy for easier notation.

class analytic_nodal_expansion.AFEN2D(xs, bc, length, symbolic=True)¶

Bases: object

Analytic Function Expansion Nodal (AFEN) for 2-dim

Parameters:

  • length (float) – the length of the node in cm

  • xs (dict) –

    includes the following keys and corresponding group values: nsfxs : group-wise fission production (nu*SigF) in 1/cm

    [1, …, G] where 1 is the fast group

    chi : fission spectrum diffxs : diffusion coefficient in cm remxs : removal cross section (rabs+out-of-group scattering) in 1/cm spmtx : group-to-group scattering production in 1/cm.

    The structure of the matrix is: 1->1, 1->2, … 1->G (from the fastest group) 2->1, 2->2, … 2->G

    keff : eigenvalue of the entire problem ng : number of energy groups

  • bc (dict) – with the following keys and corresponding group flux values: av : node average w : west surface e : east surface n : north surface s : south surface sw : south west corner se : south east corner ne : north east corner nw : north west corner

  • symbolic (bool) – whether to use real or symbolic method for evaluating functions and integrals
